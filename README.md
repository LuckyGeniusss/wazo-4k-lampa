# Wazo 4K для Lampa

Плагин Lampa с поиском торрент-релизов, выбором видеофайла и привязкой устройства к собственному Wazo 4K API.

Установка: добавить ссылку на `plugin.js` в разделе «Плагины» Lampa. Затем открыть пункт меню **Wazo 4K**, указать HTTPS-адрес своего API, запросить код привязки и подтвердить код в Telegram-боте.

Плагин содержит **только клиентский код**. Адрес API задаётся пользователем, ключей и платных источников в файле нет. Для работы необходим совместимый сервер Wazo 4K.

Статус: ранняя версия; пока проверена только в браузерной Lampa. Тест на реальном Fire TV Stick не завершён.
