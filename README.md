# Wazo 4K для Lampa

Плагин Lampa с поиском торрент-релизов, выбором видеофайла и привязкой устройства к собственному Wazo 4K API.

Установка: добавить ссылку на `plugin.js` в разделе «Плагины» Lampa. Затем открыть пункт меню **Wazo 4K**, указать HTTPS-адрес своего API, запросить код привязки и подтвердить код в Telegram-боте.

Плагин содержит **только клиентский код**. Адрес API задаётся пользователем, ключей и платных источников в файле нет. Для работы необходим совместимый сервер Wazo 4K.

Статус: ранняя версия; пока проверена только в браузерной Lampa. Тест на реальном Fire TV Stick не завершён.

## Отдельный плагин WAZO TV

Версия v0.3.0: независимый экран телеканалов в Lampa со своим ярким WAZO TV в боковом меню, категориями, языками, поиском и выбором резервного источника.

URL установки:

`https://cdn.jsdelivr.net/gh/LuckyGeniusss/wazo-4k-lampa@v0.3.0/tv/wazo-tv.js`

Общий API для Wazo 4K и WAZO TV: `https://4k.wazo.store`; токен устройства и код подтверждения через `@Wazo4KBot` используются обоими плагинами. Ссылки каналов подгружаются только после проверки подписки. Без подписки отображается привязка устройства. Код и CSS не содержат секретов.

На текущем этапе подтверждены браузерные тесты интерфейса и тесты API. Просмотр телеканалов на Fire Stick и автоматический переход к резервному потоку **посреди воспроизведения** ещё проверяются.

### v0.3.1 (beta)

Добавлен клиентский переход на запасной поток при фатальной ошибке видео, до шести вариантов. Проверены иконка, боковое меню и экран привязки в браузерной Lampa. Поведение при реальном сбое на Fire Stick ещё требует проверки.

`https://cdn.jsdelivr.net/gh/LuckyGeniusss/wazo-4k-lampa@v0.3.1/tv/wazo-tv.js`

### v0.3.2 (бета-интерфейс телевидения)

Добавлен телевизионный главный экран с 13 каталогами (рабочие потоки, украинские/ирландские, киноканалы, сериалы, детские, спорт, новости), раздельной фильтрацией по языку, логотипами каналов и пометками состояния источника. Категория «Киноканалы» означает линейные телеканалы с кино, а не библиотеку фильмов по запросу. Качество/работоспособность не гарантируются одним наличием записи в M3U.

Для Fire Stick использовать постоянный URL: `https://4k.wazo.store/tv.js`. Проверка веб-интерфейса: `node /Volumes/Wazo-Fast/Projects/Wazo4K/tests/tv_dashboard_smoke.cjs` (тестовые ответы API). Проверка с реальным Fire Stick ещё ожидает завершения просмотра фильма.

### v0.3.3

Фильтр «Только проверенные» включается по умолчанию во всех ТВ-категориях. При отсутствии проверенных ссылок можно отключить его и просмотреть ещё не подтверждённые варианты. Результат HTTP/HLS-пробы не гарантирует непрерывный просмотр.


### v0.4.3 (защита от зависшего предпросмотра)

Предпросмотр отмечается как обновляющееся видео только после сравнения нескольких реальных JPEG-кадров с сервера. При десятисекундном отсутствии движения или потере потока статус активности снимается и предлагается выбрать другой источник; после появления новых кадров статус восстанавливается. Сетевой поток по-прежнему проверяется сервером, а звук управляется отдельной кнопкой. Это **не** гарантия непрерывного просмотра и не проверка авторских прав.

Подтверждено Playwright-тестами: нормальное движение → остановка кадров → восстановление → потеря ответа; без JavaScript-ошибок. Для Fire Stick рекомендуется стабильный HTTPS-адрес https://4k.wazo.store/tv.js — он не зависит от Mac mini.
